---
title: "Get Auditorio Estelar running: backend and app setup"
description: "Set up the teatro_proyecto MySQL database, deploy the PHP backend to a local server, and build and launch the Android app in Android Studio."
---

This guide walks you through every step needed to get Auditorio Estelar running locally: standing up the MySQL database, deploying the PHP backend to a local server, and building and launching the Android app in Android Studio.

<Steps>
  <Step title="Install prerequisites">
    Make sure you have the following tools installed before you begin:

    - **Android Studio** (Hedgehog or later) — for building and running the Android app
    - **Java 11** — the app compiles against `JavaVersion.VERSION_11`
    - **XAMPP, WAMP, or LAMP** — provides the Apache and MySQL services the backend needs

    <Tip>On Windows, XAMPP is the simplest choice. On macOS, MAMP works well. On Linux, install Apache and MySQL directly via your package manager.</Tip>
  </Step>

  <Step title="Clone the repository">
    Clone the project to your local machine:

    ```bash
    git clone https://github.com/Mortir87/AuditorioEstelar.git
    cd AuditorioEstelar
    ```
  </Step>

  <Step title="Create the MySQL database">
    Start your local MySQL server, then create the database the backend expects:

    ```sql
    CREATE DATABASE teatro_proyecto CHARACTER SET utf8 COLLATE utf8_general_ci;
    ```

    Import your schema and seed data (if provided) into `teatro_proyecto`. The backend connects using the credentials defined in `backend/config/conexion.php`:

    ```php
    <?php
    $hostname = "localhost";
    $database = "teatro_proyecto";
    $username = "root";
    $password = "";

    $conexion = new mysqli($hostname, $username, $password, $database);

    if ($conexion->connect_error) {
        die(json_encode("Error: Fallo de conexión a la base de datos"));
    }

    $conexion->set_charset("utf8");
    ?>
    ```

    <Note>The default credentials use the `root` account with no password — the XAMPP/WAMP default. Update `$username` and `$password` if your MySQL instance uses different credentials.</Note>
  </Step>

  <Step title="Deploy the PHP backend">
    Copy the contents of the `backend/` directory to your server's document root:

    - **XAMPP (Windows):** `C:\xampp\htdocs\teatro\`
    - **XAMPP (macOS):** `/Applications/XAMPP/htdocs/teatro/`
    - **LAMP (Linux):** `/var/www/html/teatro/`

    Start (or restart) Apache so the PHP files are served. Verify the backend is reachable by opening `http://localhost/teatro/mostrar_cartelera.php` in a browser — you should see a JSON array.
  </Step>

  <Step title="Configure the Android app">
    Open `app/src/main/java/com/asg/auditorioestelar/RetrofitClient.java` and set `BASE_URL` to point at your backend.

    For the Android Emulator, use the special loopback alias `10.0.2.2` to reach `localhost` on the host machine:

    ```java
    public class RetrofitClient {
        // Use 10.0.2.2 to reach localhost from the Android Emulator
        private static final String BASE_URL = "http://10.0.2.2/teatro/";

        // Alternatively, point to a Cloudflare tunnel or remote server:
        // private static final String BASE_URL = "https://your-tunnel.trycloudflare.com/";

        private static Retrofit retrofit = null;

        public static Retrofit getClient() {
            if (retrofit == null) {
                Gson gson = new GsonBuilder()
                        .setLenient()
                        .create();
                retrofit = new Retrofit.Builder()
                        .baseUrl(BASE_URL)
                        .addConverterFactory(GsonConverterFactory.create())
                        .build();
            }
            return retrofit;
        }
    }
    ```

    <Note>If you are testing on a physical device connected to the same Wi-Fi network, replace `10.0.2.2` with your computer's local IP address (e.g., `192.168.1.x`).</Note>
  </Step>

  <Step title="Build and run the app">
    1. Open Android Studio and select **Open** > navigate to the cloned `AuditorioEstelar/` folder.
    2. Let Gradle sync finish. Android Studio will download all dependencies declared in `build.gradle.kts`, including Retrofit 2.9.0 and Glide 4.16.0.
    3. Select an emulator or connect a physical device running Android API 24 or higher.
    4. Click **Run** (the green play button) or press `Shift+F10`.

    The app launches on `HomeFragment`, displaying the concert billboard fetched from your local backend.

    <Tip>If the app shows no concerts, double-check that Apache and MySQL are running and that `BASE_URL` in `RetrofitClient.java` matches your server address.</Tip>
  </Step>
</Steps>
