The Auditorio Estelar backend exposes a set of PHP scripts as REST endpoints. Each script accepts JSON over HTTP and returns JSON responses, making it straightforward to call from the Android app via Retrofit or from any HTTP client.

## Base URL

The base URL is configured in `RetrofitClient.java`. The active production value points to a Cloudflare tunnel, and the local Android emulator address is kept commented out for reference:

```java
// RetrofitClient.java
private static final String BASE_URL =
    "https://wants-terrain-canvas-scholarships.trycloudflare.com/"; // server aitor
//private static final String BASE_URL = "http://10.0.2.2/teatro/config/"; // sin uso cambiar si se cierra el server
```

When running the app against a local XAMPP server, replace `BASE_URL` with the address of your local server (e.g. `http://10.0.2.2/teatro/` from the Android Emulator, where `10.0.2.2` is the emulator's alias for `localhost`).

## Content type

All requests must send `Content-Type: application/json; charset=utf-8`. All responses are also returned as `application/json; charset=utf-8`.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/registrar.php` | Register a new user account |
| `POST` | `/login.php` | Authenticate an existing user |
| `GET`  | `/mostrar_cartelera.php` | List all concerts |
| `GET`  | `/obtener_sesiones.php` | Get future sessions for a concert |
| `GET`  | `/obtener_butacas_sesion.php` | Get seat layout and availability for a session |
| `GET`  | `/obtener_calendario.php` | Get upcoming calendar events (concerts + sessions) |
| `POST` | `/confirmar_reserva.php` | Confirm a seat reservation |
